Big mono figure + caps label — the brand's signature way of stating specs.

```jsx
<StatBlock value="99.98" unit="%" label="Uptime SLA" />
<StatBlock value="1" unit="Gbps" label="Fibra óptica" align="center" />
<StatBlock value="24/7" label="Soporte" accent={false} />
```

Props: `value`, `unit`, `label`, `align` (`left | center`), `accent`. Use sets of 3–4 in a row across hero and infrastructure sections.
