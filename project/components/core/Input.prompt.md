Dark text field whose hairline border lights sky-blue on focus.

```jsx
<Input label="Correo corporativo" placeholder="nombre@empresa.com" />
<Input label="Empresa" hint="Razón social" />
<Input label="Teléfono" invalid hint="Campo requerido" />
```

Props: `label`, `hint`, `invalid`, plus all native input attributes. Uppercase mono-ish label uses wide tracking to match the system.
