Small mono-label marker for status, category and technical tags.

```jsx
<Badge>1 Gbps</Badge>
<Badge variant="success">Online</Badge>
<Badge variant="outline">AAA</Badge>
```

Variants: `neutral` (default), `sky`, `outline`, `success`, `warning`, `danger`. Always uppercase IBM Plex Mono — pairs naturally with spec figures. Default is neutral; reserve `sky` for genuinely CTA-adjacent tags.
