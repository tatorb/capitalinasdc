Dark, squared content surface with a hairline border — the brand's default container. Optional sky-glow and sky-portal rail.

```jsx
<Card variant="glow" interactive>
  <h3>Alta disponibilidad</h3>
  <p>Entorno controlado y seguro, 24/7.</p>
</Card>
<Card portal>…</Card>
```

Variants: `default` · `glow` (sky-lit, borderless) · `light` (white surface). `portal` adds the vertical sky-aperture image as a left rail; `interactive` lifts + glows on hover. Keep corners tight — this is an architectural brand.
